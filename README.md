# 🪲 ZhukoGPT

ИИ-помощник для Windows: по бинду выделяешь область экрана, скриншот уходит в бесплатную нейросеть: **Groq**, **Google Gemini**, **NVIDIA (DeepSeek)**, OpenRouter или TeamoRouter, ответ появляется в маленьком полупрозрачном синем окне.

- Окно всегда поверх остальных, его **нет на панели задач и в Alt+Tab**.
- Окно **не видно на записи и демонстрации экрана** (Discord, OBS, Zoom). Работает на Windows 10 версии 2004 и новее, отключается в настройках.
- Окно можно перетаскивать за шапку и растягивать за правый нижний угол. Позиция и размер запоминаются.
- Модели выбираются в настройках, кнопка «Обновить» загружает актуальный список (со значком 👁 — видят картинки).
- **Бесплатная DeepSeek:** через NVIDIA API (`deepseek-ai/deepseek-v4.1-flash`, видит картинки), без оплаты.
- **Шесть сервисов на выбор:** Groq, Gemini, OrcaRouter, NVIDIA, OpenRouter и TeamoRouter, у каждого свой ключ.
- **Свои промпты:** «Решить задание», «Только ответ», «Подробно объяснить», «Перевести» или свой текст. Переключаются кнопкой 📝.
- **🎧 Interview-режим (бета):** слушает звук компьютера или микрофон и подсказывает ответ на прозвучавший вопрос.
- **🎯 Точный режим:** ИИ думает дольше и перепроверяет вычисления. Включается кнопкой в шапке окна.
- **Весь экран** (`Alt+S`) и **длинные задания по кускам** (`Alt+D`, до 3 скриншотов в одном запросе).
- **Уточняющий вопрос** в поле под ответом: «почему так?», «проверь ещё раз».
- **Автопереключение сервисов:** если сервис упёрся в лимит или не отвечает, запрос уходит в другой сервис с ключом.
- **Автообновление:** новая версия скачивается и ставится одной кнопкой.
- **Распознавание текста:** модели без зрения (например, бесплатная DeepSeek у TeamoRouter) получают текст со скриншота. Его распознаёт встроенный OCR Windows, прямо на компьютере.

## ⬇ Скачать

**[Скачать ZhukoGPT.exe](https://github.com/bobopsya/zhukoGPT/releases/latest)** из раздела Releases. Python для него не нужен.

### Первый запуск: Groq (бесплатно, быстро)

1. Зайди на [console.groq.com](https://console.groq.com) и войди через Google или почту. Это бесплатно, карта не нужна.
2. Открой [console.groq.com/keys](https://console.groq.com/keys) и нажми **Create API Key**. Ключ начинается с `gsk_`.
3. Запусти ZhukoGPT: настройки откроются сами. Сервис **Groq (бесплатно)** уже выбран, модель — `qwen/qwen3.8-27b` (видит картинки). Вставь ключ и нажми **«Проверить»**, должно появиться «✓ Ключ работает • запросов на сегодня осталось: … из 1000».
4. Нажми «Сохранить», потом `Alt+Q` и выдели задание. Ответ приходит примерно за секунду.

Если модель не видит картинки (например, `gpt-oss`), программа сама распознает текст со скриншота и отправит его.

### Другие бесплатные сервисы

| Сервис | Где взять ключ | Что внутри |
|---|---|---|
| **Groq** (рекомендуется) | [console.groq.com/keys](https://console.groq.com/keys) | `qwen/qwen3.8-27b` видит картинки, `gpt-oss-120b` работает по тексту. 1000 запросов в день, ответ за ~1 с |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → Create API key | Gemini 3.x Flash, видят картинки. Лимиты смотри в AI Studio |
| **OrcaRouter** | [orcarouter.ai/console](https://www.orcarouter.ai/console) | Free-модели: DeepSeek V4 Flash, GLM 5.3 Flash (видит картинки), Hy3. Открываются после привязки давнего GitHub-аккаунта в профиле |
| **NVIDIA** | [build.nvidia.com/settings/api-keys](https://build.nvidia.com/settings/api-keys) | DeepSeek V4.1 Flash, бесплатно для разработчиков |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | Бесплатные модели с картинками, 50 запросов в день |
| TeamoRouter | [teamorouter.com/dashboard](https://teamorouter.com/dashboard) | Free-модели работают только при ненулевом балансе |

Сервис переключается в ⚙, у каждого свой ключ. Groq проверен с настоящим ключом. Gemini и NVIDIA проверены только на то, что распознают неверный ключ: с настоящими ключами мы их не тестировали.

Ключ хранится только у тебя на компьютере, в программу он не зашит. Поменять его можно в любой момент через ⚙.

Windows SmartScreen может предупредить о неизвестном издателе, потому что у exe нет цифровой подписи. Нажми «Подробнее», потом «Выполнить в любом случае».

## Свои промпты

Промпт говорит ИИ, что делать со скриншотом. В ⚙ → «Промпт» есть готовые варианты:

| Промпт | Что делает |
|---|---|
| Решить задание | Ответ первой строкой и короткое пояснение (по умолчанию) |
| Только ответ | Только ответы, без пояснений |
| Подробно объяснить | Решение по шагам, как учитель |
| Перевести | Перевод текста со скриншота на русский |

Кнопка «+ Новый» добавляет свой промпт, например «Реши задачу по химии и напиши уравнения реакций». Правила «отвечай по-русски» и «без LaTeX» добавляются автоматически. Быстро переключать промпты можно кнопкой 📝 в шапке окна.

## 🎧 Interview-режим (бета)

Для собеседований и созвонов. Кнопка 🎧 в шапке включает режим, внизу окна появляется большая кнопка **«🎙 Слушать»**.

1. Нажми «🎙 Слушать» или `Alt+E`: начнётся запись. Индикатор громкости в строке статуса показывает, что звук ловится.
2. Когда вопрос прозвучал до конца, нажми ещё раз («⏹ Ответить» или `Alt+E`).
3. Звук расшифрует Whisper у Groq, а ИИ найдёт вопрос и даст готовый ответ, который можно сказать вслух. Для технических вопросов он добавит ключевые пункты или пример кода. Сверху видно, что именно расслышано.

Кнопка рядом выбирает, что слушать:
- 🔊 **Звук ПК**: всё, что играет в динамиках или наушниках по умолчанию (Zoom, Discord, Teams, браузер);
- 🎤 **Микрофон**: микрофон по умолчанию в Windows.

Кнопка «✕» выбрасывает запись. Запись идёт не дольше 3 минут, потом отправляется сама. Скриншоты, уточняющие вопросы и `Alt+R` работают и в этом режиме. Окно по-прежнему не видно на демонстрации экрана.

Для расшифровки нужен **бесплатный ключ Groq**, даже если основной сервис другой: выбери в ⚙ сервис Groq, вставь ключ и сохрани, потом можно вернуть свой сервис. Звук сохраняется только в памяти и уходит только в Groq на расшифровку.

## Точный режим 🎯

Кнопка 🎯 в шапке окна включает точный режим: модель думает дольше и перепроверяет вычисления, а в ответ пишет только итог. Ответ приходит за 10–30 секунд (иногда до полутора минут), и бесплатные лимиты тратятся быстрее. При первом включении программа об этом предупредит.

У Groq точный режим работает в два шага: `qwen/qwen3.8-27b` переписывает задание со скриншота в текст, а `openai/gpt-oss-120b` решает его и проверяет. Если Groq упрётся в минутный лимит между шагами, программа подождёт несколько секунд и продолжит сама.

## Длинные задания и весь экран

- `Alt+S` отправляет весь монитор, на котором стоит мышка, без выделения области.
- Если задание не помещается на один экран: выдели первый кусок через `Alt+D`, прокрути, добавь ещё кусок через `Alt+D`, а последний сними через `Alt+Q`. Все куски (до 3) уйдут одним запросом. Кнопка «✕» рядом со счётчиком выбрасывает собранные куски.

## Уточняющий вопрос

После ответа под ним появляется поле «Спросить у ИИ…». Напиши, например, «почему так?» или «проверь ещё раз» и нажми Enter. ИИ помнит скриншот и свой прошлый ответ.

## Если сервис не отвечает

Вставь ключи для нескольких сервисов (например, Groq и Gemini). Если основной сервис упрётся в лимит или не ответит, запрос сам уйдёт в следующий сервис с ключом, а в строке статуса будет написано, кто ответил. Отключается в ⚙ галочкой «Лимит или сбой — сразу пробовать другие сервисы».

## Обновления

При запуске ZhukoGPT проверяет [релизы](https://github.com/bobopsya/zhukoGPT/releases). Если вышла новая версия, внизу окна появится зелёная кнопка «⬆ 1.x.x». По нажатию программа скачает новый exe, заменит себя и перезапустится; настройки и ключи сохранятся. Проверку можно выключить в ⚙.

## Бинды по умолчанию

| Действие | Бинд |
|---|---|
| Выделить область и решить задание | `Alt+Q` |
| Весь экран сразу | `Alt+S` |
| Добавить кусок длинного задания | `Alt+D` |
| 🎧 Interview: слушать / ответить | `Alt+E` |
| Показать / скрыть окно | `Alt+W` |
| Повторить последний запрос | `Alt+R` |
| Выход | `Ctrl+Alt+Q` |

Все бинды меняются в настройках ⚙. Кликни в поле и нажми нужное сочетание. Пока выделяешь область, `Esc` или правая кнопка мыши отменяют скриншот.

## Запуск из исходников

1. Установи [Python 3.10+](https://www.python.org/downloads/) и при установке отметь галочку «Add Python to PATH».
2. Получи бесплатный ключ Groq (см. «Первый запуск» выше).
3. Установи зависимости и запусти программу:
   ```
   pip install -r requirements.txt
   python ZhukoGPT.py
   ```
4. В открывшихся настройках вставь ключ и нажми «Проверить».

## Сборка в .exe

Релизы собираются автоматически через GitHub Actions: при пуше workflow `.github/workflows/release.yml` собирает exe на Windows, проверяет OCR и публикует релиз `v<версия>` из `zhukogpt/config.py`.

Собрать вручную можно так: запусти `build.bat`. Он установит зависимости, нарисует иконку-жука и соберёт файл `dist\ZhukoGPT.exe`. После этого Python для запуска не нужен.

## Где хранятся настройки

`%APPDATA%\ZhukoGPT\config.json`. Там лежат выбранный сервис, ключи, модели, бинды и положение окна.

## Если что-то не работает

### «Слишком много запросов»

У бесплатных сервисов есть лимиты. У Groq это 1000 запросов в день и 8000 токенов в минуту (примерно 7 скриншотов в минуту), у NVIDIA около 40 запросов в минуту. Подожди минуту или переключи сервис в ⚙.

### Ошибка «лимит запросов»

Нажми в настройках кнопку **«Проверить»** рядом с ключом, она покажет, сколько бесплатных запросов осталось на сегодня. В окне ошибки теперь также виден точный ответ OpenRouter.

- **Закончились бесплатные запросы на сегодня.** Без пополнения OpenRouter даёт 50 запросов в день на все бесплатные модели вместе, поэтому ошибка появляется сразу на всех моделях. Лимит обновляется раз в сутки. Если один раз пополнить баланс OpenRouter на $10, лимит станет 1000 запросов в день, а бесплатные модели останутся бесплатными.
- **Провайдер модели перегружен.** Это общий лимит для всех пользователей OpenRouter, а не твой. ZhukoGPT в этом случае сам пробует следующие модели из списка.
- **Слишком много запросов за минуту.** Лимит 20 запросов в минуту, просто подожди.

### TeamoRouter: «нет денег на балансе»

У TeamoRouter даже бесплатные (free) модели отвечают, только когда на балансе кошелька есть деньги. Кнопка «Проверить» в настройках сразу покажет, пускает ли сервис.

### «Не найден текст» / «не получилось распознать текст»

Модели без зрения (в настройках помечены 🔤) видят только текст, который распознала Windows. Выдели задание крупнее. Если Windows пишет, что языков нет, добавь язык: Параметры → Время и язык → Язык и регион → Добавить язык. Можно также выбрать модель со зрением (👁).

### Interview-режим: «Записалась тишина»

- Источник 🔊 **Звук ПК** пишет устройство вывода **по умолчанию**. Если собеседник звучит через другие наушники или колонки, сделай их устройством по умолчанию (значок динамика в трее) или переключись на 🎤.
- Для 🎤 разреши доступ к микрофону: Параметры → Конфиденциальность → Микрофон → «Разрешить приложениям для компьютеров».
- «Нужен ключ Groq»: звук расшифровывает Groq, вставь его бесплатный ключ в ⚙.

### Долго думает

Каждой модели даётся максимум 45 секунд. Если модель не ответила, программа сама пробует следующую из списка. Внизу окна идёт счётчик секунд, а кнопка **«Стоп»** останавливает запрос сразу.

- **«уже занято другой программой»**: этот бинд занят другой программой. Назначь другой в настройках.
- **Модель недоступна**: бесплатные модели на OpenRouter часто меняются. Нажми «Обновить» в настройках.
